# VITAL Scans: Data Repository

This repository stores scan results and historical evidence generated by [VITAL Scans](https://github.com/mgifford/vital-core).

**The data is kept in a separate repository to prevent the main VITAL code repository from becoming unnecessarily large.**

## How the repositories work together

- **[vital-core](https://github.com/mgifford/vital-core):** Contains the scanning engine, configuration, GitHub Actions workflows, reporting code, and documentation.
- **[vital-core-data](https://github.com/mgifford/vital-core-data):** Stores collected website scan results, historical evidence, summaries, and reporting metadata.

VITAL's automated workflows collect and update the data, then use it to generate the public reports.

## Explore the results

The collected data is published in a more accessible and understandable format through the [VITAL Scans reporting site](https://mgifford.github.io/vital-core/).

For information about the project, its methodology, limitations, or contributing improvements, visit the [main VITAL repository](https://github.com/mgifford/vital-core).

## Maintenance

This repository is primarily maintained by automated workflows. Data files should not normally be edited manually.

Issues, feature requests, and code contributions should be directed to [vital-core](https://github.com/mgifford/vital-core/issues).
